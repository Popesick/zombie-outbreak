# Zombie Outbreak Simulator – Moosburg

Browser-Sandbox-Simulation einer Zombie-Apokalypse auf einer echten Karte von Moosburg a. d. Isar.
Kartendaten: © OpenStreetMap-Mitwirkende (ODbL). Spielstände liegen lokal im Browser (localStorage).

Lokal starten: `./start.sh` und http://localhost:8765 öffnen.
Karte neu erzeugen: Overpass-Export als `osm.json` ablegen, dann `python3 tools/build_map.py`.
